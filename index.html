Browser-Based Games and Web Apps

This website showcases browser-based games and web applications developed using HTML, CSS, and JavaScript. Each project focuses on clean UI design, performance, and interactive user experiences that work directly in the browser without downloads.

The projects below demonstrate practical implementations of game mechanics, state management, user input handling, and responsive layouts. New features and projects are added regularly as development continues.

Dragon Game

Dragon Game is a browser-based role-playing game where players explore fantasy locations such as towns, caves, and dragon lairs.

Players fight monsters, earn experience points and gold, and level up their hero by unlocking new skills. The goal is to become strong enough to defeat the final boss, an evil dragon.

The game is built entirely with JavaScript and runs directly in the browser. Future updates will introduce new heroes, enemies, and gameplay mechanics.

Expense Tracker

Expense Tracker is a web-based application designed to help users manage their daily expenses by setting a total budget and tracking spending in real time.

The application updates the remaining balance instantly and stores data locally so users can continue tracking their expenses even after closing the browser. Additional features and analytics are planned for future updates.
